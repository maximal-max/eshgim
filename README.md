# 💖 No Is Not An Option

An interactive Valentine's Day website where saying "No" isn’t really an option.
Featuring emotional persuasion, sad cats, and an inevitable "Yes".

---

## 🌹 Preview

A small interactive web experience where:

* The **"No" button becomes less effective**
* The **"Yes" button keeps growing**
* Different cat reactions appear at each step
* The flow leads to a final unavoidable outcome

---

## 🚀 Features

* Dynamic text and image updates
* Step-based interaction logic
* Gradually increasing UI pressure
* Simple and responsive layout
* Mobile-friendly design

---

## 🛠️ Built With

* HTML5
* CSS3
* Vanilla JavaScript

---

## 💡 How It Works

Each time the user clicks **"No"**:

1. The message changes
2. The image updates
3. The "Yes" button increases in size

After several steps, the application enters a final state where the interaction is resolved.
